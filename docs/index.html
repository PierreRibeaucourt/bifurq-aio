Soyez prévenu quand Google invente une adresse de votre site

Les réponses de l'IA de Google (AI Overview et AI Mode) citent parfois des pages de votre site qui n'ont jamais existé. Les internautes qui cliquent arrivent sur une page d'erreur. Cet outil gratuit repère ces adresses dans votre Search Console et vous indique vers quelle page les rediriger.

Télécharger pour Windows Voir le code source

Gratuit et open source (licence MIT). Pour Windows 10 ou 11, avec Python installé (gratuit) : installez-le d'abord s'il n'est pas sur votre ordinateur.

Comment ça marche

  1. Vous connectez le compte Google qui gère votre Search Console, en lecture seule.
  2. L'outil cherche les adresses de votre site vues dans Google qui répondent en erreur et que Google n'a jamais explorées.
  3. Pour chacune, il propose la page réelle la plus proche. Vous posez la redirection vous-même.

L'analyse se relance seule, au démarrage de l'ordinateur ou chaque jour à l'heure choisie. Une notification Windows vous prévient quand une nouvelle adresse est à corriger. L'outil ne modifie jamais votre site.

Installer

  1. Si Python n'est pas encore installé sur votre ordinateur : téléchargez-le sur python.org et suivez l'installation.
  2. Téléchargez l'outil avec le bouton ci-dessus et décompressez le fichier ZIP.
  3. Double-cliquez sur installer.
  4. L'outil s'ouvre dans votre navigateur. Cliquez sur Connecter mon compte Google, choisissez le site à surveiller, et c'est tout.

Pourquoi l'outil demande l'accès à votre Search Console

Pour trouver les adresses inventées, l'outil a besoin de lire les pages de votre site que Google affiche dans ses résultats, et de savoir si Google les a déjà explorées. Il demande pour cela un seul accès, en lecture seule : webmasters.readonly. Il ne peut rien modifier dans votre Search Console.

Tout se passe sur votre ordinateur. Vos données Search Console et votre connexion Google ne passent par aucun serveur de l'auteur de l'outil, qui n'y a aucun accès. Le détail est dans les règles de confidentialité.
