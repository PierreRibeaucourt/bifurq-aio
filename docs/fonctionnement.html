Comment fonctionne l'outil

Ce qu'il signale, ce qu'il ne signale pas, et comment il vérifie chaque adresse.

En bref : l'outil ne cherche pas toutes les erreurs 404 de votre site. Il cherche les adresses que Google affiche alors qu'elles n'ont jamais existé : ce sont les seules qu'aucun autre rapport ne vous montre.

D'où viennent ces adresses

Les réponses de l'IA de Google (AI Overview et AI Mode) citent parfois une adresse de votre site qui n'a jamais existé. C'est souvent une déformation d'une vraie page : un mot sauté, une faute de frappe, un titre transformé en adresse. Ces citations comptent comme des affichages dans votre Search Console : c'est là que l'outil les repère.

Quand une adresse est signalée

Il faut que les quatre conditions soient réunies :

  1. Google l'affiche. Elle est apparue dans les résultats de Google ces 7 derniers jours, et au moins 15 fois en 3 mois, d'après votre Search Console. Ce seuil se change pour chaque site, dans Modifier.
  2. Elle n'est pas dans votre plan de site. L'outil considère les pages de votre plan de site comme vos vraies pages.
  3. Google ne la connaît pas. L'inspection d'URL de la Search Console répond « URL inconnue de Google » : Google ne l'a jamais explorée, elle n'a donc jamais existé.
  4. Elle répond en erreur. Quand l'outil la visite, votre site répond 404 (page introuvable) ou 410 (page supprimée).

Pour chaque adresse signalée, l'outil cherche dans votre plan de site la page dont l'adresse ressemble le plus, d'abord dans la même rubrique. Si elle ressemble assez, il la propose comme destination de la redirection : Sûre quand la ressemblance est nette et qu'aucune autre page n'est aussi proche, À vérifier sinon. Si aucune page ne ressemble assez, il vous signale l'adresse et vous choisissez la destination.

Ce que l'outil ne signale pas

  • Les pages supprimées sans redirection. Google les connaissait : elles ne remplissent pas la condition 3. La Search Console les liste déjà, dans le rapport Pages, motif « Introuvable (404) ».
  • Les pages d'erreur qui s'affichent comme une page normale (code 200, qu'on appelle « soft 404 »). L'outil lit le code de réponse, pas le contenu de la page : il les prend pour des pages qui fonctionnent.
  • Les adresses vues moins souvent que le seuil. L'outil les compte et l'indique sous le site, sans alerte.
  • Les adresses avec paramètres ou ancre, c'est-à-dire avec un « ? » ou un « # ». Elles sont ignorées.

Comment l'outil vérifie une adresse

Il la visite depuis votre ordinateur, comme le ferait un navigateur, et lit le code de réponse de votre site.

  • Peu de visites. Il ne visite que les adresses qui remplissent déjà les trois premières conditions, une à la fois, avec une pause d'une seconde et demie entre deux. Il n'explore pas votre site.
  • Il se présente. Dans les journaux de votre serveur, ses visites portent le nom Bifurq-AIO, avec l'adresse de ce projet.
  • Il suit les redirections. Une adresse redirigée vers une page qui fonctionne est considérée comme corrigée et sort du rapport.
  • Il revérifie. Une adresse en erreur est revérifiée chaque jour, pour voir vite que vous l'avez corrigée. Une adresse corrigée l'est une fois par semaine, pour vous prévenir si la redirection saute.
  • Il ne conclut rien d'une réponse douteuse. Accès refusé, serveur en panne, pas de réponse : l'adresse n'est ni signalée, ni considérée comme corrigée. Le site passe en Analyse incomplète et l'adresse est retestée à l'analyse suivante.

Si votre site est protégé contre les robots

Beaucoup de sites filtrent les visites automatiques avec un service comme Cloudflare, DataDome, Akamai, Imperva ou Sucuri. Si ce service bloque l'outil, c'est lui qui répond à la place de votre site, et l'outil ne peut pas savoir si l'adresse existe. L'outil l'indique sous le nom du site, en nommant la protection : « Votre site bloque l'outil (protection anti-robots Cloudflare) ».

Pour laisser passer l'outil, autorisez l'adresse IP de l'ordinateur où il est installé :

  1. Trouvez cette adresse IP : depuis cet ordinateur, cherchez « quelle est mon adresse IP » dans Google.
  2. Dans votre protection, ajoutez une règle qui laisse passer cette adresse IP. Si vous ne gérez pas vous-même la protection du site, transmettez la demande à la personne qui s'en occupe.
  3. Dans l'outil, cliquez sur Analyser maintenant : les adresses bloquées sont retestées tout de suite.

Avec Cloudflare

Créez une règle personnalisée du pare-feu (WAF) sur l'adresse IP source, avec l'action Skip. Si le blocage vient du Bot Fight Mode de l'offre gratuite, aucune règle ne permet d'y faire exception : seule sa désactivation laisse passer l'outil.

Bon à savoir

  • N'autorisez pas l'outil par son nom. N'importe quel robot peut se présenter sous le nom Bifurq-AIO et contourner ainsi votre protection. Autorisez son adresse IP.
  • À domicile, l'adresse IP change parfois. Si le blocage revient, mettez la règle à jour avec la nouvelle adresse.
  • Autre possibilité : DataForSEO. Si vous avez un compte DataForSEO, renseignez vos identifiants dans Modifier, rubrique Réglages avancés. La vérification passe alors par ce service, plus souvent accepté qu'un ordinateur ordinaire. Les protections les plus strictes peuvent aussi le bloquer.
